- Markdown 文档统一放在 `source/guide/` 下，文件名采用 kebab-case，并通过 YAML front-matter 声明元数据。
- 跨页复用的片段存放在 `source/includes/` 与 `source/includes/tags/`，通过 hexo-include-markdown 的 include 语法引用。
- 开源与企业版差异通过 `opensource.yml` / `enterprise.yml` 中的 `theme_config.tier` 字段区分，构建脚本依据该 tier 过滤或替换内容。
- 新增页面优先使用 `scaffolds/page.md` / `post.md` / `draft.md` 作为模板，保持 front-matter 结构一致。
- Netlify 函数分为两类：传统函数放在 `netlify/functions/` 返回 `{ handler }`，Edge Function 放在 `netlify/edge-functions/` 并导出默认异步函数。
