模块按用途分为两个并列子树：
- `scripts/` 下为一次性或 CI 调用的独立可执行脚本，语言混合 bash 与 Python，彼此无相互依赖；其中 `bootstrap_idea.sh` 通过 `uv sync` + `bun install --frozen-lockfile` 初始化后端 `.venv` 与前端 `web/node_modules`，`build_docker.sh` 先调用 `deploy/prebuild.sh` 再 `docker build`，`update_ml_tutorials.py` 从 `label-studio-ml-backend` 仓库拉取 README 并生成 `docs/source/guide/ml_tutorials/*.md` 及索引 HTML。
- `tools/bandit_ls_custom_checks/` 是一个独立的 setuptools 包（见 `pyproject.toml`），通过 `[project.entry-points."bandit.plugins"]` 注册 `checks.rq_enqueue.direct_rq_enqueue` 作为 Bandit 的 `B901` 检查，用于禁止直接调用 RQ 队列的 enqueue 方法，强制使用 `core.redis.start_job_async_or_sync()`。
依赖方向单向向外：脚本依赖项目根目录下的 `deploy/`、`web/`、`docs/` 等路径；Bandit 插件仅依赖 `bandit>=1.7.0`，不反向依赖 Label Studio 源码。
