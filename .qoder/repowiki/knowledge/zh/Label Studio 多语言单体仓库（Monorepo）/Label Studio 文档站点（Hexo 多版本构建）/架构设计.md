站点以 Hexo 6.3 为静态站点生成器，核心配置在 `_config.yml`，通过 `source/` 目录组织 Markdown 内容、EJS 模板、图片与插件文档；主题位于 `themes/v2/`，由 `layout/` 下的 EJS 布局与 `source/css|js|images/fonts` 资源构成。

- 双站点构建：`opensource.yml` 与 `enterprise.yml` 分别定义 `url`、`theme_config.tier`、`deploy.bucket`，配合 `_multiconfig.yml` 实现同一份源码构建 labelstud.io 与 docs.humansignal.com 两个站点。
- 国际化：`source/zh-cn/` 镜像英文目录结构，翻译状态由 `translation_status.json` 跟踪，`scripts/check-translations.js` 校验一致性。
- 内容组织：`source/guide/` 为主文档，`source/templates/` 存放标注模板，`source/plugins/`、`source/tags/`、`source/includes/tags/` 提供可被 hexo-include-markdown 引用的片段，`scaffolds/` 提供新页面脚手架。
- 构建脚本：`scripts/` 下包含自定义 Node 脚本（如 `release-notes.js`、`ignoreFilesBasedOnTier.js`、`replaceContent.js`），在生成阶段按 tier 过滤或替换内容。
- 部署与运行时扩展：`netlify.toml` 定义重定向、Edge Function 路由与开发命令；`netlify/functions/gather-feedback/` 是传统 Netlify Function（写入 Sanity），`netlify/edge-functions/` 是 Edge Function（content-negotiation.ts、open-graph-image.tsx）。
- 搜索与索引：`algolia-search-config.json` 与 `db.json` 供 Algolia 搜索使用，sitemap 路径由各 tier 配置指定。
