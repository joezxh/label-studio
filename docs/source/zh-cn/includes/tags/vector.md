### 参数（Parameters）

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| name | <code>string</code> |  | 标签名称 |
| toname | <code>string</code> |  | 要标注的图像名称 |
| [opacity] | <code>number</code> | <code>0.6</code> | 矢量的不透明度 |
| [fillColor] | <code>string</code> | <code>&quot;transparent&quot;</code> | 矢量填充颜色（十六进制或 HTML 颜色名） |
| [strokeColor] | <code>string</code> | <code>&quot;#f48a42&quot;</code> | 描边颜色（十六进制） |
| [strokeWidth] | <code>number</code> | <code>3</code> | 描边宽度 |
| [pointSize] | <code>small</code> \| <code>medium</code> \| <code>large</code> | <code>small</code> | 矢量控制点的大小 |
| [pointStyle] | <code>rectangle</code> \| <code>circle</code> | <code>circle</code> | 控制点的样式 |
| [smart] | <code>boolean</code> |  | 显示用于交互式预标注的智能工具 |
| [smartOnly] | <code>boolean</code> |  | 仅显示用于交互式预标注的智能工具 |
| [snap] | <code>pixel</code> \| <code>none</code> | <code>none</code> | 将矢量吸附到图像像素 |
| [closable] | <code>boolean</code> | <code>false</code> | 允许闭合形状 |
| [skeleton] | <code>boolean</code> | <code>false</code> | 启用骨架模式以允许分支路径 |
| [minPoints] | <code>number</code> \| <code>none</code> | <code>none</code> | 允许的最小点数 |
| [maxPoints] | <code>number</code> \| <code>none</code> | <code>none</code> | 允许的最大点数 |
| [pointSizeEnabled] | <code>number</code> | <code>5</code> | 形状被选中时点的像素大小 |
| [pointSizeDisabled] | <code>number</code> | <code>3</code> | 形状未被选中时点的像素大小 |
