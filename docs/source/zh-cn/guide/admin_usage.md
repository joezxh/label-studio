你可以在此页面找到有关你的计划和席位使用量的信息。

## Label Studio Enterprise

### 已用席位

在这里你可以看到席位数与活跃用户数的对比。

每个组织在其许可证中拥有固定数量的 Label Studio 席位。要增加席位，请联系你的 HumanSignal 账户代表。

!!! note On-premise
    本地部署可以通过设置 `LICENSE_MAX_USERS_OVERRIDE` 环境变量来使用少于其许可证允许的席位数。它只能降低许可的席位数，如果你设置得更高，部署将无法启动。席位按部署中的所有组织计算。请参阅[可用的 Helm 值](helm_values#The-global-extraEnvironmentVars-usage)。

### 许可证信息

此部分包含有关你的 Label Studio 许可证的一般信息，例如签发时间和过期时间。

它还包括以下使用量信息：

<dl>
<dt>项目</dt>
<dd>

**云端/SaaS：** 属于你当前组织的每个项目，无论状态（草稿/已发布）或工区（意味着它包括沙盒项目）。

**本地部署：** 服务器上的所有项目，无论状态或工区。
</dd>

<dt>结果</dt>
<dd>

你的组织在所有项目中创建的所有已标注区域（结果）的总数。结果是标注结果数组中的一个项——边界框、文本跨度、区域之间的关系等。
</dd>
</dl>

### 安全

只有组织所有者可以更新这些设置。

<dl>
<dt>会话超时策略</dt>
<dd>

| 字段          | 描述    |
| ------------- | ------------ |
| **最大会话时长（分钟）**         | 用户可以空闲多少分钟。如果超过此限制，他们将在下次触发请求时自动登出。<br> 任何命中后端的互动（触发 API 调用的点击、保存、轮询等）都会重置此计时器。 |
| **活动间隔最大时间（分钟）** | 绝对会话生存期。无论活动如何，会话从登录起不能超过这么多分钟；一旦达到，用户必须重新认证。 |

</dd>

<dt>已启用单点登录（SSO）</dt>
<dd>

这表示你的组织是否可以使用 SSO。

如果你处于试用组织中，或者你的许可证未启用 SSO，则 SSO 不可用。

</dd>
</dl>

### 电子邮件通知设置

确定从 [**账户与设置** 页面](user_account) 可获得哪些电子邮件偏好设置。

请注意以下几点：

* 新用户的电子邮件偏好默认启用。
* 如果你在此处禁用通知，该偏好将从他们的 **账户与设置** 页面隐藏，并对你组织中的所有用户阻止。
* 如果你重新启用通知，该偏好将再次出现在他们的 **账户与设置** 页面，并恢复为用户在组织禁用它之前的任何状态。

### 常见的 Enterprise 计费问题

查找与计费相关的常见问题的答案。

#### 如果我的计划处于非活跃状态会怎样？

如果你的 Label Studio Enterprise 订阅过期或取消，你将无法再执行标注、审阅标注，或向你的组织添加新用户。你可以登录并导出已完成的标注。

#### 如果我的活跃用户过多会怎样？

如果你的活跃用户数超过订阅允许的数量，你需要为你的 Label Studio Teams 订阅购买额外席位。当用户被分配角色时，即计为活跃用户。已邀请但尚未接受邀请的用户显示为"未激活"，不计入席位限制。

## Label Studio Starter Cloud

Label Studio Starter Cloud 具有 **用量与计费** 页面，显示有关你的订阅以及你正在使用的席位数量的信息。

!!! note
    只有组织所有者可以访问用量与计费页面。

订阅包含两个部分：

* **基础订阅** - 这是你对 Label Studio Starter Cloud 的访问权限，包含 1 个席位。
* **额外席位** - 你可以根据需要购买最多 11 个额外席位（总共 12 个）。

### 管理席位

#### 添加席位

作为所有者，转到 **组织 > 用量与计费**。点击 **管理席位** 并增加你的席位数量。

添加席位时，费用按比例计算并反映在你的下一张发票上。一个组织最多可以有 12 个席位。

#### 移除席位

在移除席位之前，你必须停用其关联的用户。你的活跃用户数不能超过席位数。

要停用用户，请转到 **组织 > 成员** 页面，并将用户的角色设置为 **停用**。

然后点击 **管理席位** 并减少你的席位数量。

移除席位时，费用按比例计算并反映在你的下一张发票上。

### 常见的 Starter Cloud 计费问题

#### 如何取消？

作为所有者，转到 **组织 > 用量与计费** 并点击 **取消**。

取消后，你的账户在付费计费周期结束前保持活跃。在此期间，你可以完全访问 Label Studio Starter Cloud 功能。

但是，取消后，你无法添加用户席位。如果你需要的用户数超过当前席位数允许的数量，必须重新激活你的订阅。

当计费周期结束后，你将继续保留对 Label Studio 的访问权限，并可以下载你的数据。但是，你将无法导入新数据、标注现有数据或创建新项目。

#### 如何续订？

如果你不取消订阅，它会在计费周期结束时自动续订。

#### 我可以升级到 Label Studio Enterprise 吗？

是的，你可以升级到 Label Studio Enterprise，请联系我们的销售：sales@humansignal.com。
