这些入职指南将帮助你在平台上开始你的角色。

Label Studio Enterprise 支持协作工作流，团队成员共同创建高质量的训练数据。该平台围绕两个主要角色设计：

## 面向标注者

如果你是 Label Studio 标注任务的新手，请从 **[标注者入职指南](onboarding_annotator)** 开始。本指南涵盖：

* 如何访问和浏览 Label Studio
* 查找并处理你被分配的项目
* 逐步的标注工作流
* 查看你的绩效分析
* 高效准确标注的最佳实践

标注者负责创建高质量的标签和标注，用于训练机器学习模型。你的工作对于构建准确、可靠的 AI 系统至关重要。

## 面向审阅者

如果你正在审阅标注任务，请查看 **[审阅者入职指南](onboarding_reviewer)**。本指南包括：

* 如何访问审阅界面
* 审阅和评估标注任务
* 向标注者提供反馈
* 理解审阅指标和分析
* 保持一致、彻底审阅的最佳实践

审阅者确保所有标注的质量和一致性，在任务进入生产之前充当质量保证层。
