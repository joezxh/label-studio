## 常规

使用这些设置来指定项目的一些基本信息。

| 字段          | 说明    |
| ------------- | ------------ |
| **项目名称** | 输入项目的名称。 |
| **描述**       | 输入项目的描述。 |
| **颜色**      | 你可以为项目选择一种颜色。在"项目"页面查看项目时，项目会以该颜色高亮显示。 |
| **任务抽样**     | <ul><li><strong>顺序抽样</strong>——任务以与数据管理器上相同的顺序显示给标注者。</li><li><strong>随机抽样</strong>——任务以随机顺序显示。</li></ul> |


## 标注界面

标注界面是项目的核心配置点。这决定了任务如何呈现给标注者。

有关设置标注界面的信息，请参阅[标注配置](setup)。

## 标注

<dl>

<dt>标注说明</dt>

<dd>

指定在用户标注任务时显示的说明。此字段接受 HTML 格式。

启用**标注前显示**可在用户进入标注流时向他们显示弹出消息。

如果禁用，用户需要点击标注界面底部的**显示说明**操作。

</dd>

<dt>实时预测</dt>

<dd>

如果你已连接 ML 后端或模型，可以使用此设置来确定是否应使用模型的预测对任务进行预标注。有关更多信息，请参阅[将 Label Studio 集成到你的机器学习管道中](ml)。

使用下拉菜单选择预测来源。例如，你可以选择[已连接的模型](#Model)或一组[预测](#Predictions)。

</dd>

</dl>

## 模型

点击**连接模型**将机器学习 (ML) 后端连接到你的项目。有关连接模型的更多信息，请参阅[机器学习集成](ml)。

你可以使用以下配置选项：

| 字段          | 说明    |
| ------------- | ------------ |
| **在提交标注时启动模型训练**         | 每次创建或更新标注时触发连接的 ML 后端启动训练过程。<br /><br />这是[主动学习循环](https://docs.humansignal.com/guide/active_learning)的一部分，随着新标注添加到数据集，模型可以持续改进。启用此设置后，会调用 ML 后端的 `fit()` 方法，使模型能够从最新标注中学习，并可能改进其对后续任务的预测。   |
| [**交互式预标注**](ml#interactive-pre-annotations)         | （在创建或编辑模型连接时可用）<br /><br />启用此选项可让模型通过提供实时预测或建议来协助标注过程。<br /><br />换句话说，当你与数据交互时（例如，在图像上绘制区域、高亮文本或向 LLM 提问），ML 后端会接收此输入并返回基于它的预测。   |


并且可以从已连接模型旁边的溢出菜单中使用以下操作：

| 操作          | 说明    |
| ------------- | ------------ |
| **开始训练**         | 手动启动训练。如果你想控制模型训练发生的时间（例如在收集了特定数量的标注后或在某些时间间隔），请使用此操作。  |
| **发送测试请求**         | （可从已连接模型旁边的溢出菜单中使用）<br /><br />用于故障排除并向连接的模型发送测试请求。   |
| **编辑**         | 编辑模型名称、URL 和参数。有关更多信息，请参阅[将模型连接到 Label Studio](ml#Connect-a-model-to-Label-Studio)。 |
| **删除**         | 移除与模型的连接。 |

## 预测

你可以在此处查看从数据管理器执行**检索预测**操作时导入或生成的预测。有关更多信息，请参阅[将预标注数据导入 Label Studio](predictions)。

## 云存储

此处可将 Label Studio 连接到云存储提供商：

* **源云存储**——这是项目源数据的保存位置。同步源存储时，Label Studio 检索要标注的数据。
* **目标云存储**——这是保存标注的位置。同步目标存储时，标注会从 Label Studio 发送到目标存储位置。

有关更多信息，请参阅[从外部存储同步数据](storage)。

## Webhooks

你可以使用 Webhooks 集成第三方应用。有关更多信息，请参阅[在 Label Studio 中设置 Webhooks](webhooks) 以及我们的[集成目录](https://labelstud.io/integrations/)。

## 危险区域

在此处，你可以访问会导致数据丢失的操作，应谨慎使用。

* **清除所有标签页**

    如果数据管理器未加载，清除所有数据管理器标签页可能会有帮助。
* **删除项目**

    删除项目会永久从 Label Studio 中移除所有任务、标注和项目数据。
