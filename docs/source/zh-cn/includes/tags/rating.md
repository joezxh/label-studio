### 参数（Parameters）

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| name | <code>string</code> |  | 元素名称 |
| toName | <code>string</code> |  | 要标注的元素名称 |
| [maxRating] | <code>number</code> | <code>5</code> | 最大评分值 |
| [defaultValue] | <code>number</code> | <code>0</code> | 默认评分值 |
| [size] | <code>small</code> \| <code>medium</code> \| <code>large</code> | <code>medium</code> | 评分图标大小 |
| hotkey | <code>string</code> |  | 用于更改评分值的快捷键 |
| [required] | <code>boolean</code> | <code>false</code> | 评分校验是否为必填 |
| [requiredMessage] | <code>string</code> |  | 校验失败时显示的消息 |
| [perRegion] | <code>boolean</code> |  | 使用此标签为区域评分而非整个对象 |
| [perItem] | <code>boolean</code> |  | 使用此标签为对象内部的项评分而非整个对象 |
