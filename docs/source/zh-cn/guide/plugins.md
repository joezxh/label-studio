你可以通过实现自定义 JavaScript 插件来扩展你的标注配置。

插件（以前称为"Custom Scripts"）在项目设置的标注界面部分中定义： 

![Screenshot of plugin panel](/images/plugins/plugin-panel.png)

!!! note
    插件在启用之前不可用。在请求访问之前，有一些[重要的安全注意事项](#Security-notes-constraints-and-limitations)需要了解。要为你的组织启用插件，请联系你的客户经理，或转到 **项目 > 设置 > 标注界面** 并点击 **请求访问**。 

!!! error Enterprise
    插件仅在 Label Studio Enterprise 中可用。它们在 Starter Cloud 或社区版中不可用。

## 使用场景

插件允许你增强和定制你的标注界面和工作流。例如：

* **通用验证** —— 插件可用于实现各种验证检查，以确保标注的质量和一致性。 

    示例：数据完整性检查、逻辑一致性检查、完整性检查。 

* **融入动态元素** —— 将动态可视化融入标注界面，以提供上下文或帮助标注者完成任务。 

    示例：图表或其他数据可视化、为任务插入自定义选项、标注的实时视觉辅助。 

* **查询外部数据库** —— 启用对外部数据库的动态查询，以获取标注任务所需的数据。 

    示例：检索上下文数据、检索最新数据以填充选项

* **工作流验证与自定义** —— 使用自定义逻辑和验证，根据当前标注任务的结果触发后续工作流或操作。 

    示例：标注者的反馈循环、条件路由/分配、渐进式采样、有关项目进度的通知。 

## 安全注意事项、约束和限制

插件是一个强大的工具，可帮助你完全自定义标注工作流。这样做你会在每个标注者的机器上运行任意 JavaScript 代码，这带来了一定的风险。 

因此，在为你组织启用插件之前，你必须选择加入，并且我们敦促你谨慎使用此功能。

要为你组织启用插件，你不能让成员属于多个组织。这是通过应用逻辑强制执行的，并且对于数据安全是必要的。最常见的原因是用户在过期的免费试用中有账户，但如果你使用多个组织进行项目管理，或者你有一个初始的概念验证或测试组织，也可能发生这种情况。 


!!! note
    默认情况下，只有具有管理员、所有者或经理角色的用户才能访问项目设置以查看、添加和编辑插件。 
    
    你可以选择添加限制，以便只有具有管理员或所有者角色的用户才能添加或编辑插件。要请求此功能，请联系你的客户经理或[提交支持工单](mailto:support@humansignal.com)。
