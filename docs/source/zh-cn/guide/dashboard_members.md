> 深入了解从事项目的成员的绩效、一致性和质量。

成员仪表板为你的项目人员提供了两个视图：一个 **绩效** 选项卡，包含标注者和审阅者的独立表格，以及一个用于标注者之间可靠性的 **一致性矩阵** 选项卡。

这在许多方面都很有用：

- **跟踪标注者和审阅者绩效**：查看关键指标，如评估状态、一致性、接受分数、绩效分数、真值一致性和耗时，以识别谁表现一致或需要支持。
- **监控标注和审阅进度**：查看标注者提交的、接受的、拒绝的或仍处于待审阅状态的标注数量。
- **识别质量和一致性问题**：使用一致性矩阵选项卡发现成员之间的分歧，然后点击单元格查看他们产生分歧的具体任务。

有关跨项目和随时间变化的成员指标，请参阅[成员绩效仪表板](dashboard_annotator)。

## 访问仪表板

从项目中，打开 **仪表板** 选项卡，并从仪表板导航中选择 **成员**。

数据质量仪表板有两个选项卡：

- **绩效**：审阅项目中单个标注者和审阅者的关键指标。
- **一致性矩阵**：比较成员、模型和真值之间的成对一致性分数。

![成员仪表板截图](/images/project/project_members_dashboard.png)

## 按参与者筛选

仪表板右上角有一个参与者筛选器。默认情况下显示为 **所有参与者**。

- 标注者在 **所有标注者** 下列出；如果项目有模型预测，模型版本会显示在 **所有模型版本** 下。
- 选择特定参与者会将绩效表和一致性矩阵都缩小到仅那些成员。

## 绩效

**绩效** 选项卡有一个开关，可在以下之间切换：

- **标注**：每个成员提交活动的指标
- **审阅**：每个成员审阅活动的指标

使用 **导出** 按钮将当前可见的表格下载为 CSV。

### 标注摘要

**标注摘要** 表显示每个项目成员的标注指标。该表可排序，并在底部包含一个总计行。使用 **列** 选择器显示或隐藏列。

| 列 | 描述 |
|--------|-------------|
| **标注者** | 成员姓名。点击可打开该成员的[成员绩效仪表板](dashboard_annotator)，并筛选到此项目。 |
| **ID** | 成员的数字用户 ID。 |
| **已暂停** | 切换以手动暂停或取消暂停标注者。请参阅[暂停标注者](quality.html#Pause-an-annotator)。 |
| **评估** | 当启用[标注者评估](project_settings_lse.html#annotator-eval)时显示。标注者和审阅者的状态：**已通过**、**未通过**、**未开始** 或 **进行中**。悬停可查看指标、分数或样本进度，以及他们上次被评估的时间。你不能使用 **已暂停** 切换来取消暂停因评估而被暂停的人。 |
| **一致性** | 在存在多个标注的任务上，与其他标注者的平均一致性分数。 |
| **已分配** | 手动分配给成员或包含成员已提交标注的任务数。 |
| **待处理** | 手动分配给成员但尚未提交或跳过标注的任务数。 |
| **已提交** | 成员提交的标注总数。包括已提交、已更新和已审阅的标注。 |
| **已跳过** | 成员跳过的任务数。 |
| **已接受** | 被审阅者接受的已提交标注数。 |
| **修复 + 接受** | 被审阅者修复然后接受的已提交标注数。 |
| **已拒绝** | 被审阅者拒绝的已提交标注数。 |
| **已更新** | 当启用[标注者评估](project_settings_lse.html#annotator-eval)时显示。最后一个操作为已更新的标注数，包括在审阅之前或之后进行的更新。 |
| **接受分数** | 已接受标注（包括修复+接受）除以已审阅标注总数。使用每个标注的最新审阅结果。 |
| **绩效分数** | 基于审阅结果（接受、拒绝、修复+接受）的整体标注绩效。请参阅[标注绩效摘要](dashboard_annotator#Annotation-performance-summaries)了解计算方式。 |
| **总 Lead Time** | 从任务打开到提交的所有标注的总耗时。包括更新所花费的时间。 |
| **平均 Lead Time** | 每个已提交标注的平均耗时。 |
| **中位 Lead Time** | 每个标注的中位耗时。 |
| **真值一致性** | 该成员的标注与重叠任务上的真值标注之间的一致性。 |
| **预测一致性** | 该成员的标注与重叠任务上的模型预测之间的一致性。 |
| **最近活跃** | 成员在项目中最近活动的日期和时间。 |

!!! note
    以下列默认隐藏，可使用 **列** 选择器显示：**ID**、**已分配**、**待处理**、**中位 Lead Time**、**预测一致性**。

### 审阅摘要

**审阅摘要** 表显示在项目中执行过审阅的每个成员的审阅活动。

| 列 | 描述 |
|--------|-------------|
| **审阅者** | 成员姓名。点击可打开该成员的[成员绩效仪表板](dashboard_annotator)，并筛选到此项目。 |
| **ID** | 成员的数字用户 ID。 |
| **已暂停** | 切换以暂停或取消暂停审阅者。 |
| **已审阅** | 已审阅标注总数。接受、修复+接受和拒绝之和。 |
| **待处理** | 手动分配给审阅者但尚未审阅的任务数。 |
| **已接受** | 被审阅者接受的标注数。 |
| **修复 + 接受** | 被审阅者修复然后接受的标注数。 |
| **已拒绝** | 被审阅者拒绝的标注数。 |
| **平均时间** | 审阅一个标注所花费的平均时间。包括修复标注所花费的时间。 |
| **总时间** | 花费在审阅上的总时间。 |
| **中位时间** | 审阅一个标注的中位时间。 |
| **最近活跃** | 审阅者最近审阅活动的日期和时间。 |

!!! note
    以下列默认隐藏，可使用 **列** 选择器显示：**ID**、**绩效**、**已提交任务**。

!!! note
    审阅时间数据收集于 2025 年 9 月 25 日在云环境开始，或在本地部署版本 2.30.0 开始。筛选更早的日期将不包括审阅时间。

### 按维度划分的绩效

**按维度划分的绩效** 表显示在标注子选项卡上的标注摘要下方。它分解了每个成员在项目中配置的每个标注维度上的绩效分数。

使用 **与…比较** 下拉菜单选择分数的计算方式：

- **与真值比较** —— 分数反映每个成员在重叠任务上与真值标注的一致性。
- **与所有标注者比较** —— 分数反映每个成员在相同的任务上与其他标注者的一致性。

一个 **平均值** 列显示每个成员在所有维度上的整体平均值。一个页脚行显示所有成员在每个维度上的平均值。使用 **列** 选择器显示或隐藏单个维度。

## 一致性矩阵 

**一致性矩阵** 选项卡显示 **成员 / 模型一致性矩阵**，这是一个热力图，显示项目中所有成员（以及模型，如果通过参与者筛选器包含）之间的成对一致性分数。

点击任何单元格可打开数据管理器，筛选到两个成员都进行了标注的任务，以便你可以直接检查分歧。

!!! note
    成员仪表板中的一致性反映标注者之间的一致性分数，无论为项目配置的是哪种[一致性方法](stats#Methodology)。

### 筛选器

- **维度**：按特定标注维度（控制标签）筛选一致性。默认为 **所有维度**。
- **标签**：筛选到至少有一个标注包含指定标签的任务。仅在选择了特定维度时可用。

### 阅读矩阵

单元格根据一致性区间进行颜色编码：

- **绿色** —— 高（≥ 66%）
- **黄色** —— 中等（33–66%）
- **红色** —— 低（< 33%）

悬停在任何单元格上可查看一致性百分比以及两个成员都进行了标注的任务数。如果存在 **真值** 列，它会显示每个成员与项目[真值](ground_truths.html)标注的一致性。

底部的 **平均值** 行显示所有成员在每个列上的平均一致性。

参与者筛选器（右上角）适用于此选项卡 —— 选择特定的标注者或模型版本以缩小矩阵范围。
