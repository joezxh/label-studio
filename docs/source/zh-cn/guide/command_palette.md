命令面板是一个增强的搜索和导航工具。

要打开它，点击右上角的搜索图标，或按 `Ctrl+K`（Mac 上为 `Cmd+K`）

![Screenshot](/images/admin/command-palette1.png)

## 你可以做什么

![Screenshot](/images/admin/command-palette2.png)

从这里你可以：

- 在你的 Label Studio 组织中搜索。例如，你可以搜索项目和工区。
- 导航到应用内的页面。 
- 查找 Label Studio 文档和资源的快速链接，例如 API 文档和变更日志。 
- 当你在某个项目内时，你可以搜索设置页面或单个设置以快速跳转到它们。 

## 感知角色的结果 

结果会尊重你的角色和访问权限。例如，标注者和审阅者不会看到他们无权访问的工区或项目。

## AI 助手

如果启用了 AI 助手，你可以输入查询然后按 Tab。助手会自动打开并显示你的查询。

## 键盘快捷键

- `Ctrl+K` 或 `Cmd+K` 打开命令面板 
- 使用 `上` 和 `下` 方向键在结果中导航
- `Enter` 选择一个选项
- `Esc` 关闭
- Tab 打开 AI 助手
