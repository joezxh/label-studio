- Python 代码风格与 lint 规则集中在根目录的 .black、.pylintrc、.codespellrc、.pre-commit-config.yaml，backend 与 scripts_and_tools 共用同一套 pre-commit hook 配置。
- Django 应用通过 DJANGO_SETTINGS_MODULE=core.settings.label_studio 环境变量启动，所有 make 目标与 Dockerfile 均遵循该约定。
- 前端静态资源经 Vite/Bun 构建后输出到 label_studio/core/static/js/，再由 Django collectstatic 合并入生产镜像。
