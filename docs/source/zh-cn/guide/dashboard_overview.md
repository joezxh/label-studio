**分析 > 概览** 页面是一个集中式的起点，用于探索多个项目的绩效洞察。 

![概览仪表板截图](/images/analytics/overview.png)

#### 按用户角色访问

| 用户角色 | 访问限制 |
|-----------|---------------------|
| **所有者** 和 **管理员** | 可以查看 **概览** 仪表板并筛选所有工区和项目。 |
| **经理** | 可以查看 **概览** 仪表板，但只能筛选和查看他们是其成员的工区或项目。  |
| **审阅者** 和 **标注者** | 无法访问 **概览** 仪表板。 <br/><br/>当他们打开 **分析** 时，会被重定向到[成员绩效仪表板](dashboard_annotator)，在那里他们只能查看自己的标注和审阅历史。 |

## 筛选

### 按项目和工区筛选

选择一个或多个工区或单个项目。要查看所有项目，请在工区筛选器的顶部选择 **所有工区**。 

这不包括个人沙盒项目，并且一次限制为 50 个项目。 

### 按日期范围筛选

你可以选择一个日期范围以应用于项目指标。如果要精确，你还可以包含时间。 

请注意，标注和接受指标是根据它们 **完成** 的时间计算的，而不是它们 **开始** 的时间。 

例如，假设你的日期范围为 2 天：周一和周二。如果标注者在周二打开一个标注，开始处理它，然后在周三提交，那么该标注以及他们花费的时间将 **不会** 包含在指标中。   

### 保存视图

你可以将日期范围和项目筛选项保存为自定义视图。保存的视图使你更容易对希望随时访问的日期和项目进行分组。 

请注意以下几点：

* 你可以保存、更新和删除视图。 
* 视图仅对你可见（意味着它们不与组织中的其他用户共享）。

!!! note
    如果你在保存日期和项目/工区筛选器后点击 **应用**，你的选择将传播到其他分析页面。你可以重新应用你的视图或将这些筛选器合并到新的或更新的视图中。 

## 任务和项目状态

有关概览仪表板中引用的状态的更多信息，请参阅[项目和任务状态管理](project_states)。 

!!! note

    项目和任务状态历史跟踪直到为你的组织实现状态管理后才开始。对于大多数 Label Studio Cloud 组织，状态管理于 2026 年 2 月实现。 

    这意味着，如果状态更改发生在状态管理实现之前，则 **概览** 仪表板将不会反映项目或任务何时更改了状态。 

## 项目进度摘要

在概览仪表板的顶部，摘要卡片显示所选日期范围和工区或项目的聚合指标。

!!! note
    当没有数据时显示破折号（`--`）。当有数据可用且值为零时显示零（`0`）。

| 指标 | 描述 |
|--------|--------------|
| **已完成任务总数** | 跨所选项目处于 [**完成** 状态](project_states#Task-states)的任务总数。 |
| **已标注任务总数** | 跨所有所选项目完成所需标注的任务总数。这包括处于 [**完成** 状态、**需要审阅** 状态和 **审阅中** 状态](project_states#Task-states)的任务。 |
| **已提交标注总数** | 跨所有所选项目提交的标注总数。包括已提交或已更新的标注，无论是否已审阅。 |
| **总耗时** | 跨所有所选项目花费在标注（lead time）和审阅上的总时间。 <br/><br/>lead time 是花费在最后一个操作为以下之一的标注上的时间：**提交**、**更新**、**修复+接受**、**接受**、**拒绝**。 <br/><br/>lead time 包括空闲时间，并在多个会话之间累积。 |

## 项目进度图表

概览仪表板包含按所选时间段分解指标的图表。 

标注和审阅的日期基于它们完成的时间，而不是开始的时间。

![概览仪表板截图](/images/analytics/overview-charts.png)

| 图表 | 描述 |
|-------|--------------|
| **任务进度** | 显示任务在所选时间段内如何经历[状态](project_states#Task-states)。|
| **已提交标注对比已接受标注** | 显示随时间的已提交标注和已接受标注，以及一条接受分数线（接受分数是已接受标注数除以已审阅标注数）。请注意，已接受标注包括被修复然后接受的标注。 |
| **花费的时间** | 显示随时间的标注和审阅耗时。包括该时间段内的总时间和每个已提交标注的平均时间。 |

## 项目进度表

**项目进度** 表显示每个项目的详细指标。 

![概览仪表板截图](/images/analytics/overview-table.png)

!!! note
    当没有数据时显示破折号（`--`）。当有数据可用且值为零时显示零（`0`）。

| 列 | 描述 |
|--------|--------------|
| **工区** | 包含该项目的工区。 |
| **项目** | 项目名称。点击可打开项目仪表板。 |
| **任务计数** | 项目中的任务数。这包括每个任务，不受日期筛选。 |
| **任务数（初始）** | 处于 [**初始** 状态](project_states#Task-states)的任务数。 |
| **任务数（标注中）** | 处于 [**标注中** 状态](project_states#Task-states)的任务数。 |
| **任务数（需要审阅）** | 处于 [**需要审阅** 状态](project_states#Task-states)的任务数。 |
| **任务数（审阅中）** | 处于 [**审阅中** 状态](project_states#Task-states)的任务数。 |
| **任务数（完成）** | 处于 [**完成** 状态](project_states#Task-states)的任务数。 |
| **已标注任务** | 在所选日期范围内各自收到所需标注数量的任务总数。这包括处于 **完成** 状态、**需要审阅** 状态和 **审阅中** 状态的任务。 |
| **已提交标注** | 已提交标注数（包括已更新和/或已审阅的标注）。 |
| **已接受标注** | 已接受或修复然后接受的标注。 |
| **总耗时** | 花费在标注和审阅标注上的总时间。 |
| **平均时间 / 标注** | 每个已提交标注的平均耗时。包括标注和审阅时间。 |
| **平均一致性分数** | 所有已收到所需标注数量的任务的平均一致性分数。 |
| **接受分数** | 已接受标注总数除以已审阅标注数。 |
