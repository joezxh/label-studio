包管理器固定为 `bun@1.3.11`（`packageManager` 字段），所有脚本通过 `bun --bun run` 执行；开发服务器默认监听 8010 并代理 `/api`、`/static` 到 `DJANGO_HOSTNAME`（默认 http://localhost:8080）；生产构建需先 `bun run build:app` 再运行 `tools/build-service-worker.mjs`；独立编辑器构建走 `lsf:build`（`vite.config.editor.ts`），Playground 走 `playground:serve`/`playground:build`（`vite.config.playground.ts`）。
