## Label Studio 如何在标注中保存结果

你在标注任务时创建的每个标注都包含区域（regions）和结果（results）。

- **区域（Regions）** 指的是所选数据区域，无论是文本片段、图像区域、音频片段还是其他实体。
- **结果（Results）** 指的是分配给该区域的标签。

每个区域在每个标注中都有一个唯一的 ID，由 `A-Za-z0-9_-` 这些字符组成的字符串构成。每个结果 ID 与其所适用的区域 ID 相同。

当使用预测来创建标注时，结果 ID 在标注字段中保持不变。这样你就可以跟踪由机器学习模型生成的区域，并将其与人类创建和审核的标注直接进行比较。
