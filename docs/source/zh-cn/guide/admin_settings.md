有多个位置可以配置组织范围的设置：

| 字段          | 访问权限    | 说明  |
| ------------- | ------------ | ------------ |
| [**用量与许可证**](admin_usage) | 所有者<br />管理员 | 此页面混合了可由管理员（启用电子邮件通知）和所有者（启用 AI、启用存储代理、启用早期采用者功能）设置的设置。   | 
| [**访问令牌**](access_tokens) | 所有者<br />管理员 | 控制组织中可用的访问令牌类型。  | 
| [**模型提供商**](model_providers)         | 所有者<br />管理员 | 设置可与 [Prompts](prompts_overview) 和 [Chat](/tags/chat.html) 一起使用的模型提供商。 | 
| [**权限**](admin_permissions)        |  所有者 | 为角色自定义某些权限。  | 
| [**支持报告**](support_reports)      | 所有者<br />管理员 | 生成匿名化的运营报告，帮助 HumanSignal 支持团队了解你的部署、诊断问题，并推荐工作流和性能改进方案。 |
