!!! note
    此页面仅对具有所有者角色的用户可见。

你可以使用此页面为角色自定义某些权限。有关 Label Studio Enterprise 角色和默认权限的信息，请参阅[用户角色与权限](admin_roles)。

请注意以下几点：

* 所有者角色的权限不可配置。所有者始终可以执行下面列出的每个操作。
* 你可以使用此页面上的选项来更精细地控制哪些角色可以执行某些操作。
* 你配置的任何限制也适用于 API。例如，如果你限制经理配置云存储的能力，他们无法通过 UI 或 API 完成这些操作。
* 某些权限只能授予特定角色。无法被授予某权限的角色没有对应的复选框。

!!! note
    标注者、审阅者和经理的权限已经限制在他们创建（如果是经理）或被明确授予访问权限的项目中。

## 成员管理

| 权限 | 可授予 | 默认 | 描述 |
|------------|-------------------|---------|-------------|
| **邀请成员加入组织** | 管理员、经理 | 管理员+ | 控制谁可以在项目级别（经理）以及组织和项目级别（管理员）邀请组织成员。<br><br>如果为经理启用，他们会在项目的 **成员** 页面获得 **邀请成员** 操作。被邀请的成员会被添加到组织并自动添加到项目。经理只能邀请用户加入他们创建或被邀请加入的项目。此权限不授予经理访问 **组织** 页面的权限。<br><br>**本地部署：** 如果你尚未配置电子邮件服务器，此设置控制谁可以生成邀请链接。 |
| **分配同级角色** | 管理员、经理 | 经理+ | 控制某个角色是否可以邀请或创建与其自身角色相同的成员。取消选中时，他们只能分配低于自身级别的角色。 |

## 集成与 API

| 权限 | 可授予 | 默认 | 描述 |
|------------|-------------------|---------|-------------|
| **创建 API 令牌** | 所有角色 | 所有角色 | 控制谁可以创建用于 API 的访问令牌。所有 API 端点也基于用户角色受到限制。<br><br>更改此设置不会使现有 API 令牌失效。要使现有传统令牌失效，请从组织级别的 **访问令牌** 页面禁用它们。要使现有个人访问令牌失效，请从组织级别使所有现有令牌过期。 |
| **编辑插件** | 管理员、经理 | 经理+ | 控制谁可以查看、修改和向项目添加[插件](plugins)。插件涉及自定义代码，可以显著更改标注界面以及标注者可以看到和访问的信息。 |
| **管理云存储** | 管理员、经理 | 经理+ | 控制谁可以访问项目的 **云存储** 页面。有权访问此页面的用户可以创建和修改[云存储](storage)连接，以将数据导入项目。 |
| **管理 Webhooks** | 管理员、经理 | 经理+ | 控制谁可以为项目创建、修改和删除[webhooks](webhooks)。Webhooks 支持与第三方应用程序的集成。 |

## 界面

| 权限 | 可授予 | 默认 | 描述 |
|------------|-------------------|---------|-------------|
| **编写界面** | 管理员、经理 | 经理+ | 控制谁可以编写或编辑附加到项目的[界面](interfaces)代码。界面代码在沙盒 iframe 中运行，但它仍然可以看到要求它渲染的任务数据，因此请像审查任何其他代码一样审查它。<br><br>需要 **管理界面**。标注者和审阅者无法被授予此权限。 |
| **管理界面** | 管理员、经理 | 经理+ | 控制谁可以访问 **界面** 部分以列出、创建、编辑、删除和复制界面。为某个角色关闭它也会为该角色关闭 **编写界面**。 |

## 分析

| 权限 | 可授予 | 默认 | 描述 |
|------------|-------------------|---------|-------------|
| **访问项目仪表板** | 管理员、经理 | 经理+ | 控制谁可以查看[项目仪表板](dashboards)。这些页面提供特定项目上下文中有关用户性能和一致性的信息。 |
| **访问成员绩效仪表板** | 所有角色 | 所有角色 | 控制谁可以查看[成员绩效仪表板](dashboard_annotator)。此页面提供一段时间内用户标注和审阅活动的指标。<br><br>标注者和审阅者只能查看自己的仪表板。经理可以查看所有组织成员的此仪表板，但只能筛选他们已经有权访问的项目。 |
| **访问项目成员仪表板** | 管理员、经理 | 经理+ | 控制谁可以查看[成员仪表板](dashboard_members)。此页面提供特定项目上下文中有关用户标注一致性的信息，包括一致性矩阵。 |

## AI 工具

| 权限 | 可授予 | 默认 | 描述 |
|------------|-------------------|---------|-------------|
| **使用 AI 助手** | 所有角色 | 经理+ | 控制哪些角色可以访问应用内[AI 助手](ask_ai)以获取帮助。如果你希望所有支持请求都转到你的内部支持组织，请禁用它。<br><br>这仅适用于每个 Label Studio 页面右上角可用的 AI 助手。要同时控制项目创建期间显示的 AI 助手，请从 **用量与许可证** 页面禁用 AI 功能。 |

## 破坏性操作

| 权限 | 可授予 | 默认 | 描述 |
|------------|-------------------|---------|-------------|
| **删除任务** | 管理员、经理 | 经理+ | 控制谁可以删除项目中的任务。 |
| **重置项目缓存** | 管理员、经理 | 经理+ | 控制谁可以执行项目的 **重置缓存** 操作。这是一个故障排除操作，重置项目标注缓存以修复标注配置验证错误。 |
| **删除所有标签** | 管理员、经理 | 经理+ | 控制谁可以执行项目的 **删除所有标签** 操作。这是一个故障排除操作，删除除 **默认** 标签之外的所有数据管理器标签。当数据管理器无法正常加载时，它可以帮助解决问题。 |
| **删除项目** | 管理员、经理 | 经理+ | 控制谁可以执行 **删除项目** 操作。具有此权限的用户可以永久删除项目及所有关联数据，包括任务和标注。 |
| **删除个人沙盒中的自有项目** | 经理 | 关闭 | 允许无法 **删除项目** 的经理删除他们在自己的[个人沙盒](workspaces#Sandbox-workspace)中创建的项目。<br><br>其他人创建的项目，以及曾经移出沙盒的项目，即使被移回，也会保持受保护。<br><br>只能在经理的 **删除项目** 关闭时选择。 |

## 依赖权限

两个权限依赖于同一角色的另一个权限：

* **编写界面** 需要 **管理界面**。如果你为某个角色关闭 **管理界面**，则该角色的 **编写界面** 也会被关闭并禁用。
* **删除个人沙盒中的自有项目** 仅在经理的 **删除项目** 关闭时可用。**删除项目** 已经允许经理删除他们可以访问的任何项目，因此如果你为经理打开 **删除项目**，则 **删除个人沙盒中的自有项目** 会被清除并禁用。如果你再次关闭 **删除项目**，需要重新选择它。

!!! info tip
    你可以点击 **重置为默认值** 将所有权限恢复为默认值。
