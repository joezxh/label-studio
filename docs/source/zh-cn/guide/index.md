欢迎使用 **Label Studio** 中文文档。

Label Studio 是一款开源的数据标注工具，支持在一个平台上管理多个项目、多个用户以及多种数据类型。你可以：

- 使用多种数据格式执行不同类型的标注任务。
- 将 Label Studio 与机器学习模型集成，为标注提供预测（预标注）或执行持续主动学习。请参阅[将机器学习接入标注流程](/guide/ml)。
- 使用 [Label Studio Enterprise 云端服务](https://humansignal.com/platform/)，获得增强的安全性（SSO、RBAC、SOC2）、团队管理、数据发现、分析与报告以及支持 SLA。
