Label Studio 模板为你提供了一种快速开始数据标注流程或机器学习工作流的方式。

这些模板是针对特定使用场景和数据类型预定义的标注界面。你可以直接使用我们的模板立即开始标注，也可以将它们作为起点，为你的数据标注项目构建完全自定义的标注界面。

正在开发某个模板并希望与社区分享？请在 [Community Slack](https://slack.labelstud.io/?source=GitHub) 中分享给我们，或[在 GitHub 上提交 issue](https://github.com/HumanSignal/label-studio/issues/new/choose)。

需要帮助来自定义我们的模板？请查看 [关于标注界面的文档](/tags)。

## 仅限 Enterprise 的模板

名称旁边带有锁形图标 🔒 的模板仅对 Label Studio Enterprise 用户可用。

## 模板组成

模板使用标签来完成以下事情：
- 定义要被标注的对象（对象标签 / Object tags）
- 定义如何标注这些对象（控制标签 / Control tags）
- 定义如何布局界面（视觉标签 / Visual tags）。

你可以自定义任何模板。[使用标签及其参数](/tags) 来自定义或扩展模板，以适配更具体的数据标注使用场景。
