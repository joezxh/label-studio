### 参数（Parameters）

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| name | <code>string</code> |  | 元素名称 |
| toName | <code>string</code> |  | 要标注的元素名称 |
| [choice] | <code>single</code> \| <code>multiple</code> | <code>single</code> | 配置可以为一个区域选择一个还是多个标签 |
| [maxUsages] | <code>number</code> |  | 每个任务中一个标签最多可使用的次数 |
| [showInline] | <code>boolean</code> | <code>true</code> | 是否在同一行显示标签 |
| [opacity] | <code>float</code> | <code>0.6</code> | 高亮标签的矩形不透明度 |
| [fillColor] | <code>string</code> |  | 矩形填充颜色（十六进制） |
| [strokeColor] | <code>string</code> | <code>&quot;#f48a42&quot;</code> | 描边颜色（十六进制） |
| [strokeWidth] | <code>number</code> | <code>1</code> | 描边宽度 |
| [value] | <code>string</code> |  | 包含动态加载标签列表的任务数据字段（见下方示例） |
