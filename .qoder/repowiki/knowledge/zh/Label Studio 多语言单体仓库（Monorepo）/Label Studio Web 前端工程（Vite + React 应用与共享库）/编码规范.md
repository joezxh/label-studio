- 组件目录采用自包含模式：每个组件文件夹内同时放置 `Component.jsx` 与同名 `Component.prefix.css`，CSS 通过 PostCSS 自动加前缀以避免命名冲突。
- 跨包依赖统一通过 `@humansignal/*` 别名导入（如 `@humansignal/ui`、`@humansignal/core`、`@humansignal/app-common`），在 `vite.config.ts` 中集中映射到 `libs/` 对应路径。
- 全局样式（Tailwind reset/utilities 与 App 级 prefix.css）通过 Vite 插件 `enforceGlobalCssOrderPlugin` 在 `main.tsx` 入口处强制注入，禁止在业务组件中隐式依赖引入顺序。
- 应用级上下文通过 `providers/MultiProvider.js` 组合多个 Provider（QueryClient、Jotai、Auth、AppStore、Api、Config、Routes、Project、Tour），新增全局能力时在此处注册而非分散挂载。
- 环境变量与后端注入的配置统一从 `window.APP_SETTINGS` 读取（开发环境由 `injectAppSettings` 插件注入占位对象，生产由 Django 渲染注入），避免直接 import 配置文件。
- 构建产物与静态资源文件名统一带 hash（`[name]-[hash].js` / `[name]-[hash][extname]`），并通过 Rollup `manualChunks` 将 react/mobx/radix-ui/tanstack/antd/codemirror/d3/jotai/konva 等大包拆分为 vendor chunk。
