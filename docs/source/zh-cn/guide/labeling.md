使用开源数据标注工具 Label Studio 对你的数据进行标注和注释。在[设置项目](/guide/setup_project)、[标注界面](/guide/setup)以及[导入数据](/guide/tasks)之后，你就可以开始标注和注释数据了。

1. 在 Label Studio 中打开一个项目，并可选地[筛选或排序数据](/guide/manage_data#Filter-or-sort-project-data)。
2. 点击 **Label All Tasks（标注所有任务）** 以[开始标注](#Start-labeling)。
3. 使用[键盘快捷键](#Use-keyboard-shortcuts-to-label-regions-faster)或鼠标为数据打标签并提交你的注释。
4. 遵循项目的标注说明，并决定是否跳过某些任务。
5. 点击项目名称返回数据管理器。

你还可以[与其他标注人员协作](#Label-with-collaborators)以提高标注数据的质量。

## 开始标注

某些标注任务可能比较复杂，例如在一个数据集和标注任务中同时包含文本、图像和音频数据对象，或者在标注任务中的注释之间建立关联。本节包含如何执行更复杂标注任务的指导，例如带关联关系的标注、重叠区域、选定任务或更改标签。

### 选择要标注的任务

在一个项目中，点击 **Label All Tasks（标注所有任务）** 以开始标注所有任务。或者，选择 **Label Tasks As Displayed（按显示顺序标注任务）**，以按照数据管理器中筛选和排序后的顺序进行标注。

你也可以通过在项目数据管理器视图中点击某个任务，在 **Quick View（快速预览）** 或 **Preview（预览）** 中标注特定任务，但提交注释后不会自动跳转到标注队列中的下一个任务。

你也可以勾选特定任务旁边的复选框，然后点击 **Label $n Tasks（标注 $n 个任务）** 来标注选定数量的任务。例如，勾选 5 个不同任务的复选框，然后点击 **Label 5 Tasks（标注 5 个任务）**，即可只标注这 5 个任务。

!!! note
    在标注任务时，你不应在两个标签页中同时打开标注流（即点击 **Label All Tasks**）。这可能导致你收到同一个任务两次，从而绕开项目中用于处理标注人员重叠（overlap）的设置。

### 为数据中的某个区域打标签

通过添加一个区域来标注数据的一部分。

1. 选择要应用到该区域的标签。对于某些配置，你可以跳过此步骤。
2. 点击文本、图像、音频或其他数据对象，将标签应用到该区域。你的更改会自动保存。
3. 点击 **Submit（提交）** 以提交完成的注释并进入下一个任务。

### 标注重叠区域

当你使用边界框和其他图像分割任务进行标注，或者为 NLP 和 NER 标注高亮文本时，可能需要标注重叠区域。为此，可以在标注后隐藏已标注的区域，以便操作。

1. 选择要应用到该区域的标签。
2. 绘制边界框或高亮你要标注的文本。
3. 在 **Regions（区域）** 或 **Labels（标签）** 侧边栏中，找到并选中你标注的区域，然后点击眼睛图标以隐藏该区域。
4. 或者按 cmd 或 ctrl 键在现有 **Regions（区域）** 或 **Labels（标签）** 上绘制（注意：此操作不适用于关键点 Keypoints）。
5. 选择要应用到重叠区域的下一个标签。
6. 绘制边界框或高亮你要标注的文本。
7. 继续隐藏和标注区域，直到完成该任务的标注。如果需要，可以点击 **Regions（区域）** 旁边的眼睛图标，隐藏然后重新显示任务上标注的所有区域，以确认最终结果。
8. 点击 **Submit（提交）** 以提交完成的注释并进入下一个任务。

### 选择多个区域

你可以在标注时选择多个区域，以便一起修改它们。

1. 创建多个区域后，按 `ctrl` 并点击你要选择的每个区域。你可以选择正在标注的对象上的区域，或在 **Regions（区域）** 侧边栏中的区域。在 **Regions（区域）** 侧边栏中选择一系列区域的方法是：点击你要选择的列表中的第一个区域，然后在按住 `Shift` 的同时点击列表中你要选择的最后一个区域。
2. 选择区域后，你可以为所有选中的区域应用标签，或者删除它们。
3. 点击选中的区域或按 `u` 键取消选择。

### 复制区域

你可以复制一个区域来创建多个相同大小的多边形、矩形或椭圆。

1. 选择要复制的区域。
2. 按 `ctrl + d` 复制该区域，或使用 `ctrl + c` 和 `ctrl + v` 的连续操作来复制并粘贴该区域。复制的区域会出现在被复制区域的完全相同位置。如果你使用的是 Mac 键盘，请用 `cmd` 代替 `ctrl`。
3. 点击箭头工具，然后移动并调整新创建区域的大小。

### 更改标签

你可以更改现有区域的标签。

1. 在对象上或使用 **Regions（区域）** 侧边栏，选择已标注的区域，例如文本片段、边界框、图像分割、音频区域或其他区域。
2. 选择一个新的标签。你对标签的更改会自动保存。
3. 点击 **Submit（提交）** 以提交完成的注释并进入下一个任务。

### 删除已标注的区域

如果需要，你可以删除已标注的区域，例如边界框或文本片段。

1. 在对象上或在 **Regions（区域）** 侧边栏中选择已标注的区域。
2. 按 Backspace 键，或进入 **Results（结果）** 面板并移除选中的注释。

### 删除注释

标注完一个任务后，你可以点击垃圾桶按钮删除该任务上的注释。如果你尚未保存注释，请点击 `X` 图标以重置任务并清除你的标注操作。

你也可以从项目页面删除任务上的所有注释。请参阅[删除任务或注释](/guide/manage_data#Delete_tasks_or_annotations)。

### 在注释之间添加关联关系

你可以使用双向和标签在两个结果之间创建关联关系。若要为方向添加标签，必须使用包含 relations 标签的标注配置进行设置。有关更多信息，请参阅标签文档中的[带标签的关联关系](/tags/relations.html)。
