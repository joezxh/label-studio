**分析 > 标签分布** 仪表板显示标注和预测值在项目中是如何分布的。使用它来识别不平衡的标签、比较标注者和模型的输出，并深入查看标签值背后的任务。

![标签分布仪表板截图](/images/analytics/label-dist.png)

## 按用户角色访问

| 用户角色 | 访问限制 |
|-----------|---------------------|
| **所有者** 和 **管理员** | 可以查看 **标签分布** 仪表板并筛选所有项目。 |
| **经理** | 可以查看 **标签分布** 仪表板，但只能筛选和查看他们是其成员的项目。  |
| **审阅者** 和 **标注者** | 无法访问 **标签分布** 仪表板。 <br/><br/>当他们打开 **分析** 时，会被重定向到[成员绩效仪表板](dashboard_annotator)，在那里他们只能查看自己的标注和审阅历史。 |

## 按维度划分的标签分布

仪表板按标注维度对结果进行分组。维度可以来自传统的标注配置控制标签，也可以来自界面输出，例如 ReactCode 或 CustomInterface 字段。

每个受支持的维度都有一张卡片，包含：

- **平均一致性**：当有足够数据比较标注、预测或真值时，该维度的一致性。
- **标签分布图表**：比较标注和预测值的分组水平条形图。
- **标签明细表**：每个值的标注和预测计数。

![标签分布仪表板截图](/images/analytics/label-dist-charts.png)

## 标签明细表

标签明细表显示所选维度的每个值，外加一个 **总计** 行。

| 列 | 描述 |
|--------|-------------|
| **标签** | 标签或值名称。最后一行显示所有值的总计。 |
| **来自标注** | 该值在标注中出现的次数。 |
| **来自预测** | 该值在预测中出现的次数。 |

**来自标注** 和 **来自预测** 列中的值可以链接到数据管理器，其中已应用所选项目、维度、值和来源的筛选器。使用这些链接来检查底层任务、标注或预测。

![标签分布表截图](/images/analytics/label-dist-tables.png)

## 受支持的维度

标签分布支持具有有限值集合的维度，包括：

- 标签控件，例如 `<Labels>`、`<RectangleLabels>` 和其他基于标签的控件。
- 选择控件，例如 `<Choices>`。
- 具有有限、嵌套选择的分类法控件。
- 枚举支持的 ReactCode 和 CustomInterface 维度。
- 其他可以表示为已知值集合的有限标量维度。

没有有限值集合的维度不会显示为标签分布。这包括自由文本、任意数值或日期值、对象、数组以及未在维度模式中声明的值。

!!! note
    如果某个维度不受支持，仪表板应显示它不受支持，而不是渲染空图表。这有助于区分"无数据"与无法安全汇总为标签分布的数据。
