### 参数（Parameters）

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| [height] | <code>number</code> | <code>200</code> | 绘图高度 |
| [showAxis] | <code>boolean</code> | <code>true</code> | 是否显示两个坐标轴 |
| [showYAxis] | <code>boolean</code> | <code>true</code> | 是否显示 y 轴 |
| [fixedScale] | <code>boolean</code> |  | 是否对所有通道使用固定比例。若未设置，则继承自父级 TimeSeries 标签 |
