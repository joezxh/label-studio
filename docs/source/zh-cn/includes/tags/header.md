### 参数（Parameters）

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| value | <code>string</code> |  | 页眉文本，可以是静态文本，也可以是数据中用于页眉的字段名 |
| [size] | <code>number</code> | <code>4</code> | 页面中页眉的级别，用于控制文本大小 |
| [style] | <code>string</code> |  | 页眉的 CSS 样式 |
| [underline] | <code>boolean</code> | <code>false</code> | 是否给页眉加下划线 |
