欢迎来到 Label Studio 平台！

在本文档中，我们将快速帮助你了解数据标注。每个项目都用于根据其特定用例来训练模型。

可以通过 Label Studio 实现多种用例，包括但不限于预训练、训练后、基准测试等。

本质上，你标注的每一项任务都是让你的团队模型变得更好的一种方式。无论你是拥有博士学位的专家，还是精通研究的通才，都需要你的知识和能力来训练模型。

通常，在你提交任务后，Label Studio Enterprise 会将所有已提交的标注任务发送给审查者，由他们验证是否存在任何错误。具体步骤因团队而异，但大多数工作流都遵循这样的模式：标注 → 审查与质量保证 → 生产。

在质量保证步骤中，任务会被评估和评分。评分基于它们与项目协议的贴合程度。

### 你需要什么

* **电脑**
  虽然有些团队可能对可使用的设备类型比较灵活，但强烈建议你使用笔记本电脑或台式机，因为移动设备通常在项目涉及较大文件时没有足够的处理能力，也无法理想地显示较长的任务。

  向你的团队负责人确认是否有关于你可以使用哪种设备的限制。在某些情况下，你当前的公司硬件可能未被批准或不是标注的首选。

* **项目协议**
  在你的入职期间，你的团队负责人应提供有关项目工作流和步骤的文档。根据你头几天的时长和范围，负责人通常会带你完成一两个任务，以便你有一定的指导。或者，你可能会看到视频录制，让你自己了解协议。

* **适当的账户权限**
  当你的 Label Studio 账户创建时，你的团队负责人需要将你添加到适当的项目以便你工作。有时，你可能会被添加到多个项目，因此确保你有权访问并正在处理你优先级最高的项目非常重要。

  以下视图是你的主页仪表板在你被分配了项目时 *应该* 的样子。这意味着你的权限已设置好，你已经准备好开始工作！

## 演练：

### 我如何访问 Label Studio？

当你最初获得 Label Studio 访问权限时，你会收到一封电子邮件和一个注册链接。

要访问你公司的项目，请使用你在注册时提供的信息登录。（位置链接可能会根据你团队是直接在 Label Studio 上工作，还是在你公司自己的集成工作区中工作而有所不同。）

![Screenshot](/images/onboarding/annotator-2.png)

### 我如何找到我的项目？

你最近的项目会在你登录时显示在主页上。你可以选择将你的优先项目固定到此部分。

![Screenshot](/images/onboarding/annotator-3.png)

或者，点击仪表板顶部的汉堡菜单（hamburger menu）打开侧边菜单并查看你的“项目（Projects）”文件夹。如果你点击文件夹但没有看到正确的项目列出，你的权限可能尚未更新。请联系你的团队负责人解决此问题。

![Screenshot](/images/onboarding/annotator-4.gif)

### 我的项目有既定期望吗？

确切的标准会在入职期间讨论。在那段时间，你的负责人通常会传达：

* 给定时间内的期望任务产出
* 目标评分平均值
* 每个任务预计花费的时间
* 等等。

### 你如何进行标注？

1. 选择你想要工作的项目。

    ![Screenshot](/images/onboarding/annotator-5.png)

2. 当你点击“label”时，你会被带到你的第一个任务。

   ![Screenshot](/images/onboarding/annotator-6.png)

3. 标注任务。如果由于某种原因你无法完成任务（例如，不是主题专家等），请点击“Skip（跳过）”按钮。如果没有可用的“Skip”，请就这里的最佳做法咨询你的团队负责人。

4. 遵循你的负责人给你的协议。在此示例中，标注者正在选择图像中的汽车。你的项目可能被配置为允许在 Label Studio 中弹出标注说明。如果是这样，你可以通过点击标注屏幕底部、提交按钮左侧的带有字母 i 的圆圈图标来查看它。

5. 在侧边栏的“Info（信息）”标签页下添加或编辑信息。你也可以在“Comments（评论）”标签页中为你的审查者或团队负责人留下评论。

   ![Screenshot](/images/onboarding/annotator-7.png)

6. 完成任务的流程后，点击“Submit（提交）”按钮发送你的任务并进入下一个任务。

   按钮右侧还有一个下拉菜单，允许你提交任务然后退出项目。但是，为避免意外留下未完成的草稿，请仅在你已完成任务并退出项目时才保留此选项。

   ![Screenshot](/images/onboarding/annotator-8.png)

### 我如何查看我的标注统计？

1. 点击 LSE 平台顶部的汉堡菜单按钮。

2. 点击 Analytics（分析）。

   ![Screenshot](/images/onboarding/annotator-9.png)

3. 你的整体统计会包含在此仪表板中。你可以看到你提交的总标注数、用于标注的时间以及整体绩效分数。这些图表还直观地展示了你随时间的生产流程。如果你想调整日期范围，可以在分析仪表板的右上角进行。

   ![Screenshot](/images/onboarding/annotator-10.png)

4. 如果你愿意，你还可以导出你的分析以供自己记录。

   ![Screenshot](/images/onboarding/annotator-11.png)

## 标注者最佳实践

#### 将你的项目协议放在手边以便轻松参考

将你的项目协议放在手边以便轻松参考。

无论你是将其打印出来还是在第二个屏幕上打开，拥有一份项目步骤和关键说明的“备忘单”对新手和经验丰富的标注者都很有用。

对于刚起步的人来说，这更容易遵循正确的步骤——尤其是在工作流微妙或容易被误解时。

对于更有经验的标注者来说，这减少了在忘记细节时来回切换的需要，并有助于在具有挑战性的任务或较长班次期间保留脑力。

#### 研究每一个细节，即使是那些“听起来正确”的

特别是对于具有冗长或微妙响应的任务，模型可能会产生幻觉。对于外行来说似乎准确的预标注或模型派生的答案，可能包含甚至很小的错误。随着数据集变得更加复杂，标注者也应该更加细致。如果模型在此基础上训练，不准确性可能会被放大，从而导致整个模型的重大挫折。

#### 主动查看分析

项目标准应该在你的入职期间宣布。在转变的情况下，期望也需要调整。在这些情况下，你的团队负责人或项目的联系人通常会传达在规定时间段内应完成多少任务、每个任务平均花费的时间、每个任务的目标与平均评分等。

留意这些统计数据，因为它们可以让你自我监控成功率，并评估你在项目理想方面的位置。此外，认识到你可能不足之处会告知你在哪里需要改进。

#### 调整自己的节奏

在你的统计数据的支持下，请确保你保持节奏以满足“理想”的分析。将你的时间和精力视为不可再生的资源。精神疲惫和急于完成任务的冲动都可能导致错误增加。

#### 尽可能在一天开始时处理最困难/最长的任务

有些项目允许你在处理分配的任务之前先审查它们。如果是这样，请考虑在开始工作时将你的精力集中在最耗费时间和精力的任务上。这可以让你在精神疲劳较少时更容易专注于复杂任务，从而可能导致更少的粗心错误。当然，在做此之前，请咨询你的团队负责人，以确保这在项目协议中是允许的。

#### 跟踪你的生产力何时下降，以及如何回到正轨

根据项目不同，你的工作方式可能会波动。你产出最多标注的时间不一定总是早上；它可能是在你喝完咖啡休息后或午饭前。当这种情况发生时，尝试不同的方法来让自己重新进入状态。

对于某些人来说，为这些低谷保存“更简单”的任务可能会有帮助，而在任务中间暂停以伸展休息可以让其他人立即重新投入，快速参考其详细笔记以回到暂停工作的正轨。

#### 知道何时向负责人标记问题

如果你遇到故障，你并不总是需要立即给你的负责人发消息。首先，捕获一些细节以便他们快速排查故障：你在做什么、发生了什么、任务 ID，以及截图（如果可能）。当问题被清晰记录并可复现时，它们更容易修复。

这同样适用于反馈和评分。如果某些内容看起来令人困惑或不正确，请注意这看起来是一次性故障还是跨多个任务的模式。无论哪种方式，都要提出来，特别是如果它影响你的分数或绩效指标。反复出现的问题应该更早升级，因为它们可能影响整个项目。

#### 记录提高你效率的策略

当你对项目的协议感到舒适时，请注意哪种方法对你最有效。文档中可能有一些技巧，但它们不一定总是对你或每个任务最有效。

记录哪些研究技术或网站对你事实核查的任务来说是可靠的。这可以作为你可以点击浏览的“备忘单”，从而节省每次需要资源时都要查找的时间。

#### 与更有经验或得分高于你的人建立关系

尽可能与经验更丰富或结果持续强劲的队友建立联系。许多人很乐意分享不一定会进入项目文档的实用技巧。

经验丰富的标注者有时间完善他们的工作流，并提高速度和质量。学习他们的方法可以帮助你更快地建立自己的工具包。

与你可以进行合理性检查的受信任同伴建立关系也很有帮助，特别是如果那些队友也担任审查者。
