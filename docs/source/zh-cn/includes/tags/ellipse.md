### 参数（Parameters）

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| name | <code>string</code> |  | 元素名称 |
| toName | <code>string</code> |  | 要标注的图像名称 |
| [opacity] | <code>float</code> | <code>0.6</code> | 椭圆的不透明度 |
| [fillColor] | <code>string</code> |  | 椭圆的填充颜色（十六进制） |
| [strokeColor] | <code>string</code> | <code>&quot;#f48a42&quot;</code> | 描边颜色（十六进制） |
| [strokeWidth] | <code>number</code> | <code>1</code> | 描边宽度 |
| [canRotate] | <code>boolean</code> | <code>true</code> | 显示或隐藏旋转控件 |
| [smart] | <code>boolean</code> |  | 显示用于交互式预标注的智能工具 |
| [smartOnly] | <code>boolean</code> |  | 仅显示用于交互式预标注的智能工具 |
