## 为什么要审查标注？

数据标注是训练许多机器学习模型的关键步骤，并且审查标注以确保只有最高质量的数据被用于训练你的机器学习模型至关重要。如果你不审查标注数据的质量，弱标注可能会被用于训练你的模型，从而降低整体模型性能。

## 审查已标注的任务

在你 [将审查者分配给任务](#Assign-reviewers-to-tasks) 之后，他们可以审查已标注的任务。管理员和项目经理可以随时审查任务，而无需被添加到项目中。

1. 审查者可以点击某个特定项目的 **审查标注（Review Annotations）**，然后在数据管理器上点击 **审查所有任务（Review All Tasks）** 开始审查任务。管理员和项目经理可以从数据管理器或 **探索审查（Explore Review）** 点击任务。
2. 审查第一个任务和标注。

    默认情况下，你按照任务呈现给标注者的顺序查看任务。如果你想更改审查任务的顺序，请参阅 [选择要审查的内容](#Choose-what-to-review)。

    - 如果标注正确，点击 **接受（Accept）**。
    - 如果标注基本正确，你可以通过选择一个不同的选项、更改选定的区域、移动边界框，或任何对你正在审查的标签类型有意义的方式来修正它。修正标注后，点击 **修正并接受（Fix & Accept）**。
    - 如果标注错误，或者你不想自己尝试修正，请点击 **拒绝（Reject）** 以拒绝该标注。

        点击 **拒绝** 会应用项目的默认拒绝选项。如果项目有多个可用的拒绝选项，你可以打开拒绝菜单以选择如何处理拒绝：

        - **无需返工（No Rework）** —— 标注被拒绝并且不会发回进行返工。
        - **退回给标注者（Return to Annotator）** —— 标注被发回给原始标注者，以便他们可以更新它。
        - **传递给另一个标注者（Pass to Another Annotator）** —— 任务被发送给不同的标注者以进行新的标注。原始标注者不能再更新被拒绝的标注。

        你看到的选项取决于项目的 [**拒绝选项（Reject Options）**](project_settings_lse#reject-options) 设置。

3. 继续审查已标注的任务，直到你审查完所有已标注的任务。点击 **数据管理器（Data Manager）** 返回项目的任务列表。

!!! info 提示
    如果有多个标注，你可以通过标注者和结果 ID 选择每个标注的标签页来分别查看它们。[标注结果 ID](labeling.html#How-Label-Studio-saves-results-in-annotations) 不同于左侧菜单中可见的任务 ID。要并排查看标注，你可以在数据管理器中点击任务，并在任务预览模式下查看标注网格。

### 选择要审查的内容

你可以以随机顺序审查任务，或者以不同的方式对项目的任务进行排序，具体取决于你的用例：

- 按标注者排序任务，以便在审查标注的同时评估单个标注者的表现。
- 按一致性排序任务，以便首先审查标注者之间不确定性更高的标注。
- 按模型置信度分数排序任务，以便首先审查机器学习模型不太确定的标注。

#### 任务排序与限制（Enterprise）

打开 **设置 > 审查 > 任务排序（Settings > Review > Task Ordering）** 以选择审查流呈现任务的方式。**随机（Random）** 和 **按标注者（By Annotator）** 需要 Label Studio Enterprise。有关 **按标注者** 覆盖率如何工作的信息，请参阅 [任务排序](project_settings_lse#review-task-ordering)。要决定哪些任务进入审查流，请使用 [审查抽样](project_settings_lse#review-sampling)。

| 排序方式 | 审查者看到的内容 |
| --- | --- |
| **按任务 ID（By Task ID）** | 按任务 ID 升序排列的任务。任务内的标注保持稳定的顺序。 |
| **随机（Random）** | 随机顺序的任务。任务内的标注保持稳定的顺序。 |
| **按标注者（By Annotator）** | 一次一个标注者，直到该标注者剩余标注的设定份额被审查完。 |

### 在任务或标注之间导航

当设置了 `在所有标注都被审查后任务被视为已审查（Task is reviewed after all annotations are reviewed）` 选项时，你现在可以沿着与向前移动相同的路径向后浏览审查流。后退（`<`）功能会将你带回与向前移动时相同的标注集合。

1. 作为 **管理员（ADMINISTRATOR）**，登录到 [Label Studio 应用](https://app.heartex.com/projects/?page=1)。

2. 如有需要，导航到 **所有项目（All Projects）** 页面。

3. 打开任意项目。

4. 观察你被带到 **数据管理器（Data Manager）**。

5. 导航到 **设置** >> **审查（Review）**。

6. 选择 `在所有标注都被审查后任务被视为已审查` 选项。

7. 点击 **保存（SAVE）** 按钮。

8. 导航回数据管理器。

9. 确保设置了几个任务，每个任务正好有两个标注，但没有审查。

10. 点击 **审查所有任务（REVIEW ALL TASKS）** 按钮。

11. 观察你被带到审查流（Review Stream）。

12. 记下你所在的任务或标注。

13. 完成此标注的审查。

14. 观察你被带到同一任务（第二个标注）。

15. 将步骤 12 到 14 重复几次。

16. 使用后退（`<`）按钮在审查流中向后导航。

!!! note
    确认你没有被带到与向前移动时相同的路径。

### 将审查者分配给任务

作为管理员或项目经理，你可以将审查者分配给任务，或者有权访问的人可以临时审查任务。任何被分配给任务或完成某项任务审查的人都会出现在数据管理器的 **审查者（Reviewers）** 列中。你必须首先 [将审查者添加到项目](setup_project.html#Add-members-to-a-project) 或 [将成员添加到项目工作区](manage_users.html#Add-or-remove-members-to-a-workspace)，然后才能将其分配为审查者。

1. 对于特定项目，在数据管理器上选择任务。
2. 选择任务下拉菜单并选择 **分配审查者（Assign Reviewers）**。
3. 选择审查者的姓名并点击 `>` 箭头将其分配给所选任务。
4. 点击 **分配（Assign）**。

你可以一次将审查者分配给多个任务，但不能一次从多个任务中移除审查者。

## 审查项目质量仪表板

使用项目仪表板来审查标注者活动、一致性和标签分布。对于某个项目，点击 **仪表板（Dashboard）** 以查看项目级仪表板。

如果你没有在仪表板上看到标注者的活动反映出来，请确保他们已被添加为项目的成员。

### 审查标签分布

使用 [标签分布仪表板](dashboard_distribution) 来查看标签和维度值如何分布在标注和预测中。使用此仪表板来识别你的数据集分布中可能存在的问题，例如标注数据中过度表示的标签。

例如，如果你正在开发一个 OCR 图像数据集，并且 90% 的任务具有 **文本（Text）** 标签，而 10% 具有 **手写（Handwriting）** 标签，你可能想要增加数据集中手写图像的数量，以提高最终在此数据集上训练的机器学习模型的准确性。

## 暂停标注者

对于有大量标注者的组织来说，暂停标注者的进度可能会很有用。这对于表现不佳或表现出可能表明他们已将其工作自动化的行为（机器人行为）的标注者可能会有帮助。

### 完全暂停与灵活暂停

被暂停的用户保留多少访问权限取决于他们被暂停的原因：

| 暂停类型 | 描述 |
| ------------- | ------------ |
| **完全暂停（Full pause）** | 当用户被 [手动暂停](#Manually-pause-an-annotator) 或基于 [行为触发器](#Behavior-based-triggers) 暂停时适用。<br><br />用户完全失去对项目的访问权限。他们无法标注、审查、评论或更改他们自己现有的标注。 |
| **灵活暂停（Flexible pause）** | 当用户因 [每个标注者的任务限制](project_settings_lse#annotation-limit) 或 [标注者评估](project_settings_lse#annotator-eval) 而被暂停时适用。<br><br />用户保留对项目的访问权限，以便他们可以处理退回给他们的被拒绝标注。他们无法开始任何新的标注工作。有关更多信息，请参阅 [从灵活暂停中恢复](#Recover-from-a-flexible-pause)。 |

暂停仅限制触发它的工作类型。标注限制和标注者评估都衡量标注工作，因此灵活暂停仅停止新的标注工作。如果被暂停的用户也是审查者，他们可以继续审查。只有完全暂停才会阻止用户进行审查。

!!! note
    当项目的 [**拒绝选项**](project_settings_lse#reject-options) 不包含 **拒绝并退回给标注者** 时，灵活暂停会作为完全暂停生效。在这种情况下，被拒绝的标注永远不会退回给标注者，因此他们没有什么可恢复的。

### 手动暂停标注者

你可以从项目中成员仪表板的成员仪表板手动暂停标注者。此操作仅在标注者和审查者角色的用户旁边可用：

![Screenshot of pause](/images/review/pause.png)

手动暂停用户始终是一次完全暂停。当用户被暂停时，会发生以下情况：

* 他们会立即看到一条消息，告知他们已被暂停。

    ![Screenshot of message](/images/review/paused-message.png)
* 他们在当前任务内的进度会作为草稿保存，但他们无法再进行任何更改。
* 当他们点击 **返回（Go Back）** 时，他们会被返回到项目页面。如果他们尝试重新进入项目，会向他们显示上面的错误消息。

!!! info 提示

    如果你将鼠标悬停在 **已暂停（Paused）** 指示器上，你可以看到用户被暂停时显示的消息。如果用户是手动暂停的，它还会显示是谁发起了该操作。

    ![Screenshot of hover](/images/review/paused-tooltip.png)

### 自动暂停标注者

#### 标注限制设置

你可以使用 **设置 > 质量 > 标注限制（Settings > Quality > Annotation Limit）** 来设置标注者在被暂停之前能够完成的任务数量限制。有关更多信息，请参阅 [标注限制](project_settings_lse#annotation-limit)。

#### 标注者评估设置

你可以使用 **设置 > 质量 > 标注者评估（Settings > Quality > Annotator Evaluation）** 来自动暂停未达到真实标签一致性或接受分数阈值的标注者。有关更多信息，请参阅 [标注者评估](project_settings_lse#annotator-eval)。

#### 基于行为的触发器

如果你启用了 [插件](plugins)，你可以根据某些行为自动暂停标注者，然后自定义在其屏幕上显示的消息。

有关更多信息，请参阅 [插件 - 垃圾邮件与机器人检测](/plugins/pause_annotator)。

### 从灵活暂停中恢复

当用户处于灵活暂停状态时，他们保留对项目的访问权限，以便他们可以修正审查者拒绝的标注。让这些标注被接受是他们摆脱暂停的方式。

处于灵活暂停状态的用户可以做以下事情：

* 重新进入项目。如果项目启用了 **向标注者显示数据管理器（Show Data Manager to annotators）**，他们可以使用数据管理器。否则，他们只能使用标注流。有关更多信息，请参阅 [标注选项](project_settings_lse#annotating-options)。
* 更新他们自己被拒绝的标注。在标注流中，只会向他们提供他们被拒绝的标注，并且他们无法跳过它们。
* 添加评论，以便他们可以回应审查者的反馈。

他们无法开始任何新的标注工作，并且无法更新未被拒绝的标注。

一旦他们更新了所有被拒绝的标注，他们会看到一条消息，告诉他们没有更多任务可用，直到他们的更多工作被审查。

!!! note
    更新被拒绝的标注本身不会解除暂停。暂停会一直保持，直到用户再次满足项目要求。有关每次暂停如何解除，请参阅 [每个标注者的任务限制](project_settings_lse#annotation-limit) 和 [标注者评估](project_settings_lse#annotator-eval)。

## 验证模型与标注者性能

要验证特定标注者的性能，请审查特定项目的 [成员仪表板](dashboard_members)。如果你没有看到标注者的活动反映出来，请确保他们已被添加为项目的成员。

### 审查标注者性能

对于每个项目，使用 [成员仪表板](dashboard_members) 来了解更多关于标注者、审查者、模型、审查结果和整体一致性的信息。

了解谁在该项目上工作过、他们完成了多少标注和审查、他们花了多少时间，以及他们的工作与其他标注者、真实标签标注或模型预测相比如何。

查看一个表格，以了解每个标注者的以下内容：

- 一个标注者与其他标注者的总体一致性。有关 [标注者一致性如何计算](stats.html) 的更多信息。
- 已分配、待处理、已提交或已跳过的任务数量。
- 他们跳过的任务数量。
- 他们执行的标注的审查结果。
- 他们的性能分数和接受分数。
- 他们的标注者评估状态（如果启用了 [标注者评估](project_settings_lse#annotator-eval)）。
- 他们的平均、中位数和总耗时。
- 他们的标注与真实标签标注的一致性（如果有）。
- 他们的标注与预测标注的一致性（如果有）。

### 审查标注者一致性矩阵

你还可以使用 [成员仪表板](dashboard_members) 一致性矩阵在更个人的基础上审查整体标注者一致性。

审查一致性矩阵以了解哪些标注者的标注始终与其他标注者的标注一致或不一致。你可以按维度和标签过滤矩阵，或者在有预测可用时包含模型版本。有关 [标注者一致性如何计算](stats) 的更多信息。

要查看导致一致性的具体标注，请执行以下操作：

1. 打开项目的 **数据管理器**。
2. 找到你想要比较的由不同标注者标注的任务。
3. 点击任务以打开任务预览。
4. 点击每个标注标签页，比较不同标注的差异。每个标注者的姓名首字母会出现在标签头中，并带有标注 ID。

### 审查跨任务的一致性分布

使用 [数据质量仪表板](dashboard_data_quality) 来审查项目任务间一致性百分比的分布。具有较高一致性的任务越多，你的数据集质量可能越高。较低一致性分数的集群可能意味着某些任务令人困惑、难以一致地标注，或者需要更清晰的说明。

## 针对真实标签标注审查标注

在 Label Studio 项目中定义真实标签标注。使用真实标签标注来评估你的标注数据集的质量。审查真实标签，以确保标注者在项目开始时就准确地标注数据，并贯穿训练数据集创建的整个生命周期。

Label Studio Enterprise 将标注者的标注和模型预测与任务的真实标签标注进行比较，以计算 0 到 1 之间的准确度分数。

!!! note
    真实标签标注仅在 Label Studio Enterprise 版中可用。如果你使用的是 Label Studio 社区版，请参阅 [Label Studio 功能](https://labelstud.io/guide/label_studio_compare.html) 以了解更多信息。

## 为项目定义真实标签标注

从项目的 **数据管理器** 页面将特定任务标注设置为真实标签标注。

1. 找到你想要为其设置真实标签标注的任务。
2. 点击任务以预览该任务的所有标注（标签页形式）。如果某个标注已被设置为真实标签，标签页中的标注 ID 旁边会有一颗黄色星号。
3. 在任务的标注侧边栏中，点击标注 ID 旁边的星号图标，将该标注结果设置为真实标签。

一个任务只能有一个标注被设置为该任务的真实标签标注。如果你为一个任务设置新的标注作为真实标签，该任务先前设置为真实标签的标注将被更新为不再是真实标签标注。

## 管理项目的真实标签标注

审查并修改项目的真实标签标注。

### 审查现有的真实标签标注

你可以调整数据管理器列以显示任务是否有任何标注被设置为真实标签标注。

1. 在 **数据管理器** 上，选择 **列（Columns）** 下拉菜单。
2. 选择 **真实标签（Ground Truth）** 的复选框。会显示一个带有星号图标以及任务对应 true 或 false 值的列，指示是否已为任务设置真实标签标注。
3. 再次点击 **列** 以关闭菜单。

你还可以过滤数据管理器以仅显示带有真实标签标注的任务，以便你可以审查它们。

1. 在 **数据管理器** 上，选择 **过滤器（Filters）** 下拉菜单。
2. 点击 **+ 添加过滤器（+ Add Filter）** 并选择 **真实标签（Ground Truth）** 为 **是（yes）**。数据管理器更新为仅显示设置了真实标签标注的任务。
3. 再次点击 **过滤器** 以关闭菜单。

### 移除真实标签标注

要移除真实标签标注，

1. 在查看项目的数据管理器时，选择已标注任务旁边的复选框。
2. 在所选任务下拉菜单中，选择 **删除真实标签（Delete ground truths）**。这不会删除标注，而是将标注的真实标签设置状态更改为 false。

你也可以在标注任务时移除真实标签。

1. 在标注任务时，创建标注或选择现有标注。
2. 点击星号图标以取消将标注结果设置为真实标签。
