根目录作为 monorepo 入口，通过三层装配把子模块串联起来：
- 构建层：`Makefile` 提供 `run-dev` / `frontend-dev` / `test` / `fmt-*` 等命令，分别调用 `uv run python label_studio/manage.py ...` 启动 Django、`cd web && bun run dev` 启动前端 HMR、以及 pre-commit hooks；`pyproject.toml` 声明 Python 依赖与 entry point `label-studio = label_studio.server:main`。
- 镜像层：`Dockerfile` 使用多阶段构建——先用 `oven/bun` 编译前端产物到 `label_studio/core/static/js/manifest.json`，再用 `uv sync` 安装 Python 依赖并执行 `collectstatic`，最终由 Nginx + uWSGI 在 `deploy/docker-entrypoint.sh` 中启动 Django，从而把 frontend 与 backend 打包进同一镜像。
- 运行层：`docker-compose.yml` 及 MySQL/MinIO 变体编排数据库、Redis、Nginx 与 app 服务；`deploy/` 下的 nginx/uwsgi/初始化脚本是前后端共享的运行时契约。
- 开发环境：`.pre-commit-config.yaml`、`.pre-commit-dev.yaml`、`.black`、`.pylintrc`、`.codespellrc` 在仓库根统一配置代码质量钩子，被 backend/frontend/docs_site 共同遵守；CI/CD 工作流位于 `.github/workflows` 并通过自定义 Action 复用。
