### 参数（Parameters）

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| name | <code>string</code> |  | 元素名称 |
| toName | <code>string</code> |  | 要标注的图像名称 |
| [opacity] | <code>float</code> | <code>0.9</code> | 关键点的不透明度 |
| [fillColor] | <code>string</code> | <code>&quot;#8bad00&quot;</code> | 关键点填充颜色（十六进制） |
| [strokeWidth] | <code>number</code> | <code>1</code> | 描边宽度 |
| [strokeColor] | <code>string</code> | <code>&quot;#8bad00&quot;</code> | 关键点描边颜色（十六进制） |
| [smart] | <code>boolean</code> |  | 显示用于交互式预标注的智能工具 |
| [smartOnly] | <code>boolean</code> |  | 仅显示用于交互式预标注的智能工具 |
| [snap] | <code>pixel</code> \| <code>none</code> | <code>none</code> | 将关键点吸附到图像像素 |
