评论是 Label Studio Enterprise 的一项功能，允许审阅者和标注者之间进行沟通：

</td>

- 回答问题

这种标注者-审阅者反馈循环是你审阅工作流中的重要工具，使你能够：

- 加快标注过程
- 提高标注质量
- 建立更稳固的标注和审阅流程

![Screenshot of comments](/images/review/comments.png)


## 权限

所有用户对他们本来有权查看的任何标注具有以下评论权限：

- 查看 **评论** 面板并阅读以前的评论。 
- 添加新评论。 

其他权限如下：


| 操作          | 标注者 | 审阅者及更高角色|
|-----------------|:---------:|:--------:|
| 添加评论     | true      | true     |
| 查看评论    | true      | true     |
| 解决/重新打开自己的评论 | true     | true     |
| 解决/重新打开他人的评论 | false     | true     |
| 删除自己的评论 | true     | true     |
| 删除他人的评论 | false     | false     |
| 链接/取消链接自己的评论 | true     | true     |
| 链接/取消链接他人的评论 | false     | false     |


## 添加评论

你可以在查看标注时从 **评论** 面板添加评论。所有用户都可以访问 **评论** 面板。 

![Screenshot of comments](/images/review/comment_panel.png)

### 将评论链接到区域和字段

你可以将评论链接到标注内的特定区域。 

这可以是一个区域（例如，边界框或一段文本），也可以是一个字段（例如分类）。

![Gif of linking a comment](/images/review/comment_links.gif)

请注意以下几点：

* 你可以将评论链接到标注配置中的字段。但是，如果该字段是分类、选择项或分类法，只有在已有选择时才能附加评论。 
* 你只能将评论链接到整个文本区域。你不能将评论链接到文本区域内的区域。 
* [Ranker](/tags/ranker) 或 [Pairwise](/tags/pairwise) 字段不支持链接。 

## 评论操作

你可以执行的操作取决于[你的用户角色权限](#权限)以及是否是你的评论。你可以从溢出菜单访问评论操作：

![Screenshot of comment action menu](/images/review/comment_actions.png)


## 筛选评论

数据管理器有几个列来显示评论信息：

| 列          | 描述 | 查看权限 |
|-----------------|:---------:|:--------:|
| **评论文本**    | 评论中的文本。      | 所有用户角色   |
| **评论数**    | 特定任务的评论总数。      | 所有用户角色      |
| **未解决的评论** | 尚未解决的评论总数。      | 所有用户角色      |
| **评论时间** | 发表评论的日期和时间。      | 除标注者外的所有用户角色     |
| **评论作者** | 撰写评论的用户。     | 除标注者外的所有用户角色     |

!!! note
    审阅者或标注者角色的用户必须被授予查看数据管理器的权限。你可以在[项目设置](project_settings_lse)中授予访问权限。


## 要求评论

你可以配置项目，使标注者和审阅者在执行特定操作后必须留下评论：

* [**标注 > 标注选项 > 标注者在跳过时必须留下评论**](project_settings_lse#Annotation)
* [**审阅 > 拒绝选项 > 审阅者在拒绝时必须留下评论**](project_settings_lse#reject-options)

## 评论通知

要查看通知，请点击右上角的用户个人资料图标。 

使用溢出菜单将通知标记为已读或未读。


![Screenshot of notifications](/images/comments-notifications/notifications.png)


!!! note
    已读的通知以灰色背景表示。 

### 标注者

标注者可以在自己的标注上写评论。 

**发送的通知**

当标注者写评论时，被通知的用户取决于它是否是该标注的第一条评论：

* 如果这是该标注的第一条评论，那么项目中具有审阅者或更高角色的所有用户都会在他们的[通知列表](#通知)中看到该评论。 
* 如果此评论是对评论面板中正在进行的讨论的回复，那么只有已向该标注添加评论的用户才会看到通知。 

**收到的通知** 

当另一个用户在他们的某个标注上留下评论时，标注者会收到通知。 

### 审阅者和其他用户

审阅者可以在他们正在审阅的标注上写评论。这适用于具有审阅者、经理、管理员和所有者角色的用户。 

**发送的通知**

当审阅者写评论时，被通知的用户取决于他们的角色以及他们是否也留下了评论： 

* 标注者会收到关于他们创建的标注上的所有评论的通知。 
* 如果其他用户也留下了关于该标注的评论（例如，如果多个用户正在审阅该标注），那么当新评论出现时，他们也会收到通知。 

**收到的通知** 

审阅者在以下情况时会收到通知：

* 如果评论是该标注的第一条评论，那么项目中具有审阅者或更高角色的所有用户都会在他们的[通知列表](#评论通知)中看到该评论。 
* 如果你已经在该标注上留下了评论，那么当任何用户（无论角色）添加新评论时，你都会收到通知。
