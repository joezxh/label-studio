### 参数（Parameters）

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| value | <code>string</code> | 选项值 |
| [selected] | <code>boolean</code> | 指定是否在标注界面中预选此选项 |
| [alias] | <code>string</code> | 选项的别名。若使用，别名会在标注结果中替代选项值。别名不会在界面中显示。 |
| [style] | <code>style</code> | 复选框元素的 CSS 样式 |
| [hotkey] | <code>string</code> | 用于选择的快捷键 |
| [html] | <code>string</code> | 可用于显示富文本内容，优先级高于 `value`，但导出结果中仍使用 `value`（需正确转义） |
| [hint] | <code>string</code> | 悬停时显示的选项提示 |
| [color] | <code>string</code> | 分类法（Taxonomy）项的颜色 |
