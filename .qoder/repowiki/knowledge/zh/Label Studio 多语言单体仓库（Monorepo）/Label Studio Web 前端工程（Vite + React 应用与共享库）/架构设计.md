采用 monorepo 结构，根目录 `web/` 通过 Vite 配置集中管理多入口构建：
- `apps/labelstudio/src` 是主 SPA 入口，`main.tsx` 仅做初始化（注册 Sentry、热键、Service Worker），由 `app/App.jsx` 组装 Router、MultiProvider（QueryClient/Jotai/Auth/AppStore/Api/Config/Routes/Project/Tour）、AsyncPage/DraftGuard/ErrorBoundary 后挂载到 DOM。
- `libs/` 下为可被主应用引用的共享库：`ui`（设计系统、shadcn 组件、Tailwind 主题、i18n、tokens）、`core`（telemetry、providers、hooks、schema）、`datamanager`、`editor`、`app-common`、`frontend-test`、`storybook`；通过 `vite.config.ts` 中的 alias 以 `@humansignal/*` 别名暴露。
- `apps/playground` 是独立的预览/调试入口，使用 `vite.config.playground.ts` 单独构建。
- `apps/labelstudio-e2e` 使用 Cypress 做端到端测试。
- CSS 管线通过自定义 PostCSS 插件链（`postcss-import` → `postcssPreProcessGlobalBlocks` → `postcss-nested` → `postcssPrefixLsfClasses` → Tailwind → Autoprefixer）实现类名前缀隔离与全局样式注入顺序强制（`enforceGlobalCssOrderPlugin`）。
- 构建产物输出到 `dist/apps/labelstudio`，并通过 `tools/build-service-worker.mjs` 生成 SW，Django 侧通过 `vite-manifest-plugin` 读取 manifest。
- 工具层 `tools/` 提供 design-system 检查 (`ds-check`)、manifest 生成 (`ds-manifest`)、指标采集 (`ds-metrics`)、design-tokens 转换、Biome 插件等内部 CLI。
