CLI 命令统一由 `label_studio/server.py` 解析：`label-studio init [project_name]` 初始化 DB+用户+项目，`label-studio start [project_name]` 启动开发服务器（自动迁移、端口探测、可选打开浏览器），`label-studio reset_password`、`label-studio user`、`label-studio export`、`label-studio shell`、`label-studio version`、`label-studio calculate_stats_all_orgs`。可通过 `--config` JSON 文件与 `DJANGO_SETTINGS_MODULE=...` 环境变量注入配置。
